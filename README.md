# [Business Name] — Website

A Next.js (App Router) site for Reiki and Personal Training services.

## Structure

- `app/page.tsx` — Home
- `app/about/page.tsx` — About
- `app/reiki/page.tsx` — Reiki services, approach, background, pricing
- `app/training/page.tsx` — Personal Training, same format as Reiki
- `app/booking/page.tsx` — Contact info for booking
- `components/Nav.tsx` — Site navigation (highlights current page)
- `components/Footer.tsx` — Site footer
- `app/globals.css` — Design tokens and shared styles
- `app/layout.tsx` — Root layout, fonts, Nav/Footer wrapper

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
